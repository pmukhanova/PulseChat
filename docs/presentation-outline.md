# План презентации PulseChat

Формат: 15 слайдов, 16:9, 9–11 минут вместе с демонстрацией. На слайде — один тезис, одна схема или один фактический экран. Полные тексты, таблицы API и исходный код в основные слайды не переносятся.

1. **PulseChat. Кейс №1 «Мессенджер»** — автор, цель, обязательный сценарий.
2. **Что требуется от MVP** — auth, DIRECT/GROUP, сообщения, история, поиск, роли и real-time.
3. **Пользовательский путь** — зарегистрироваться, найти чат, написать, увидеть обновление без reload.
4. **Интерфейс: чаты и сообщения** — фактический экран приложения.
5. **Архитектура** — `architecture.svg`: React, Nginx, NestJS, PostgreSQL, REST и Socket.IO.
6. **Модель данных** — крупная проекторная версия ER: пять таблиц, PK/FK, связи и основные UNIQUE.
7. **Авторизация и доступ** — bcrypt, JWT, membership check, роли.
8. **Отправка сообщения** — крупный главный путь Client → Gateway → membership → MessageService → PostgreSQL → personal rooms → clients → ack; retry вынесен в отдельный callout.
9. **Синхронизация без reload** — `realtime-sync.svg`: personal rooms, новый чат, unread, смена роли.
10. **Роли в GROUP** — OWNER / ADMIN / MEMBER и два уровня защиты.
11. **История и поиск** — cursor pagination вверх и `ILIKE` в доступном чате.
12. **Проверка качества** — реальные команды: lint/build, Compose, миграция, seed, 21 backend tests, Playwright.
13. **Границы MVP** — отсутствие broker/Redis, read receipts, вложений и SLA; почему это осознанно.
14. **Итог и демонстрация** — выполненные требования и основное видео 125,08 секунды.
15. **Приложение** — полная техническая `send-message-sequence.svg` для вопросов по реализации.

В презентации используются четыре SVG из `docs/` и три фактических screenshot из `artifacts/screenshots/`. Итоговый файл: `artifacts/presentation.pptx`.
